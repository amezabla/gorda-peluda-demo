# Gorda Peluda Demo

Este repositorio contiene una demo estática para mostrar un prototipo de gestión financiera y control operativo.

## Qué muestra la demo

- pantalla de inicio
- módulo de compras
- alta de compra de ejemplo
- detalle de compra
- vista de control con filtros
- secciones pendientes para ventas y bancos

## Importante

- Es un prototipo de validación.
- Todos los datos son ficticios.
- No representa una aplicación de producción.
- Los datos se mantienen solo en memoria durante la sesión.
- Si recargas la página, la demo vuelve a los ejemplos iniciales.

## Cómo abrirla

Abre el archivo `index.html` en el navegador o sirve esta carpeta con un servidor estático simple.

## Estado

La demo está en validación y su objetivo es mostrar el flujo visual y la estructura básica del producto antes de definir requisitos definitivos.
